# Sakhalin Web Development

Минималистичные сайты для малого бизнеса Сахалина.  
Чистый северный дизайн, аккуратная структура и высокая скорость.

## Особенности
- Спокойный минималистичный интерфейс  
- Быстрая загрузка и лёгкие страницы  
- Чистая архитектура без перегруза  
- Адаптация под мобильные устройства  
- Простая поддержка и обновления  

## Разделы сайта
- Услуги  
- Примеры проектов  
- Подход  
- Сроки и оплата  
- Контакты  

## Технологии
- React / Next.js  
- Tailwind CSS  
- Vercel / Netlify (деплой)
